# Factory/Automation Games on HP ZBook 15 G3

> Research: which games from [Orbital Potato — "Factorio Is OVER! The Best NEW Automation Games To Play Next!"](https://www.youtube.com/watch?v=nG0nBMXryaw) (2026-06-13) can run on a ZBook 15 G3.

## Laptop Baseline (HP ZBook 15 G3, 2016)

- CPU: Intel Core i7-6820HQ / i7-6700HQ (Skylake, quad-core)
- GPU: NVIDIA Quadro M1000M (2GB GDDR5, GM107, 512 shaders) or M2000M (4GB)
- M1000M ≈ GeForce GTX 750 Ti / GTX 950M class (3DMark 11 ≈ 4,230; below GTX 660 Ti desktop)
- Real-world 1080p med: Fortnite 40-45, BF5 30-33, GTA V 24-27, Witcher 3 ~19

## Verdict by Tier

### Tier 1 — Runs great (2D / very light)
- Mindustry (2D, runs on anything)
- Sandustry (2D)
- Swarmdustry (2D, Mindustry-like)
- Biofactory (2D)
- Alchemy Factory (2D indie)
- Substructure (2D Factorio-like)
- Factory Town (3D low-poly, very light)
- Factory Town 2: Paradise (same engine style)
- Modulus: Factory Automation (3D low-poly, light)
- Launch Window (small indie)

### Tier 2 — Runs on low/medium 3D (min req ≈ GTX 660 / 750 Ti)
- shapez 2 — min GTX 750 Ti → low preset 1080p OK
- FOUNDRY — min GTX 660 (2GB) → low OK
- Astro Colony — min GTX 660; dev tested on a 920M → OK
- Captain of Industry — low, CPU heavy late game
- Timberborn — low/medium, CPU heavy late game
- Dyson Sphere Program — min GTX 660 Ti; playable at low, early/mid game

### Tier 3 — Too heavy / not recommended
- Satisfactory (min GTX 770; realistically needs ~GTX 1050+; ~15-25 FPS on low)
- StarRupture (heavy 3D)
- The Crust (Unreal 3D, borderline at low)
- Kardashev (probably heavy 3D — verify)
- Main Sequence (2026, unknown — verify)

## Tips
- Play at 720p/900p, not 1080p; enable FSR/DLSS-quality upscalers where available
- Steam refund (≤2h playtime / 14 days) is a free compatibility test
- Verify any game: https://www.systemrequirementslab.com (or Steam page min requirements)
