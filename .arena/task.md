# Task: Synthesize "Deep Research Like a Scholar" guide

## Source
Video: https://www.youtube.com/watch?v=maDmHC_NIKY
User's rough notes + transcript provided. Produce a clean, navigable guide that:
- Keeps every idea from notes + transcript
- Repairs garbled speech-to-text against transcript
- Preserves user's self-flagged interpretations (marked as user's)
- Corrects factual errors (transcript wins on conflicts)
- Navigable for someone who hasn't seen the video

## Key content to include

**Approaches:**
- Top-down: start with idea → research to narrow → idea + research
- Bottom-up: forage for interesting fragments → filter relevant → question → become topic
- Tip: can shift from bottom-up to top-down

**Depth & Breadth:**
- Depth: how deep (professor/engineer level vs high-school)
- Breadth: niche vs general

**Literature entry (shallow media):**
- Use digestible sources (YouTube, summaries, articles) to build concept map before diving
- Tip: check relevance, don't put all energy in one source
- Tip: need multiple sources (6+ books/articles) for different POVs
- Translations can change meaning
- Don't lose references

**Schedule & environment:**
- Consistent daily/weekly time (Atomic Habits)
- Dedicated place that affords focus (not gaming desktop)
- Journal to process emotional "trolls"

**Workflow — 4-level funnel (video) + Commonplace Book as synthesis hub:**
1. Inspection: glance-relevant filter
2. To Read: deeper dive on promising items
3. Insights: connect relevant ideas to your questions
4. Order: how ideas/books connect to each other
5. Commonplace Book: where ordered insights live (not a 5th funnel level)

**Tips for sources:**
- Rephrase/highlight in your own words what connects
- Find what's wrong/missing/biased/weak in each source
- Connect dots across sources into singular ideas
- Make an index/overview page to retrieve sources

**Critical thinking — CRAP test (4 criteria, NOT CRAAP):**
- Relevance: different POVs on same question, aligns with your view
- Currency: timeliness
- Authority: expertise
- Purpose: bias/agenda
- Tip: read multiple sources
- Tip: hesitate to judge — need full picture
- Tip: seek challenges — avoid confirmation bias
- Paragraph breakdown: arguments, evidence, assumptions, limitations

**Understand your limits:**
- Sources written for experts (high lexile)
- Use shallow media as bridge, but know they're filtered
- Accept what you can't digest

**Output:**
- Goal to keep going (article, blog, video, wiki)
- Future-oriented motivation

## Deliverable
Clean, structured markdown guide with:
- Table of contents
- Clear sections matching above
- User interpretations marked "👤 User addition"
- Garbled→fixed glossary appendix
- Quick-reference checklist at end
